# Notater – Claude Code 101

## Huskeliste

### Før kurset
- [ ] Logg inn på claude.ai og sjekk at du har tilgang til Claude Code
- [ ] Koble GitHub-kontoen din til Claude
- [ ] Ha minst ett repo klart å øve i (f.eks. `hei-verden`)

### Grunnleggende
- [ ] Forklar oppgaven tydelig – si *hva* du vil ha og *hvor* det skal lagres
- [ ] Be Claude lese koden før den gjør endringer
- [ ] Gå gjennom endringene før de lagres (commit) og sendes til GitHub (push)
- [ ] Bruk små steg – én ting om gangen er lettere å kontrollere

### Nyttige kommandoer
- [ ] `/init` – lager en `CLAUDE.md` med informasjon om prosjektet
- [ ] `/code-review` – ber Claude se over endringene for feil
- [ ] `/help` – viser hjelp og tilgjengelige kommandoer

### Git og GitHub
- [ ] **Commit** = lagre et øyeblikksbilde av endringene
- [ ] **Push** = sende endringene til GitHub
- [ ] **Branch** = en egen arbeidsgren, så `main` holdes ryddig
- [ ] **Pull request** = forslag om å slå en branch sammen med `main`

### Etter kurset
- [ ] Prøv å lage et lite prosjekt på egen hånd
- [ ] Skriv ned spørsmål du vil ta opp neste gang
- [ ] Oppdater denne lista med egne tips
